# 🚘 Project Overview

Smart Vehicle Health Monitoring System is an IoT-based automotive monitoring solution designed to continuously track critical vehicle parameters and provide real-time health status information.

The system collects data from multiple sensors and displays important vehicle diagnostics, helping detect potential issues before they become major failures.

This project demonstrates concepts used in modern connected vehicles, predictive maintenance systems, and automotive diagnostics.

- Detect abnormal operating conditions

# 🚗 Parameters Monitored

### 🌡️ Engine Temperature

Monitors temperature levels and alerts when overheating occurs.

### 🔋 Battery Voltage

Tracks battery condition and voltage fluctuations.

### ⚡ Current Consumption

Measures power usage and detects abnormal loads.

### 📶 Real-Time Data Transmission

Transfers sensor data to a monitoring dashboard.

### 🚨 Fault Detection

Identifies abnormal operating conditions and alerts users.

# 🏗️ System Architecture

```text
Vehicle Sensors
      │
      ├── Temperature Sensor
      ├── Voltage Sensor
      └── Current Sensor
              │
              ▼
          Arduino Uno
              │
              ▼
        ESP8266 Module
              │
              ▼
      Cloud / Dashboard
              │
              ▼
       User Monitoring
```

---

# 🔄 Working Principle

1. Sensors collect vehicle health data.
2. Arduino processes sensor readings.
3. ESP8266 transmits data wirelessly.
4. Dashboard displays real-time values.
5. Alerts are generated if abnormal conditions occur.
